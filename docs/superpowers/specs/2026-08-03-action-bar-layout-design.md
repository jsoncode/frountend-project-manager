# 操作栏布局重构设计

**日期：** 2026-08-03  
**状态：** 已批准（方案 A）

## 目标

将原右侧竖条工具窗迁移到文件目录右侧，命名为「操作栏」；去掉「信息」；标题行右侧为搜索（仅过滤当前 Tab）。

## 布局

```
[ Explorer | 操作栏 ] | [ 编辑器 + 终端 ]
```

- 去掉 DetailPane 内最右侧 ToolWindow / tool-strip
- Sidebar 变为：Explorer + 竖向拖拽 + ActionBar（竖向铺满）
- 操作栏宽度独立持久化（沿用 `toolPanelWidth`）

## 操作栏 UI

1. 标题行：左「操作栏」，右搜索框  
2. 标题下横向 Tab：分支 / IDE / 命令 / 环境（无「信息」）  
3. Tab 内容区：复用现有面板逻辑  
4. 搜索：仅过滤当前 Tab 列表项；切换 Tab 可清空或保留关键词（实现：保留，按新 Tab 重新过滤）  
5. 始终显示一个 Tab（默认命令）；不再支持「收起为空」

## 非目标

- 跨 Tab 搜索  
- 并列多面板 stack 模式  
- 信息（meta）面板
